## Summary

DGF 1.3.1 renders Word and PDF documents in process with LeanDocPdf. The Syncfusion, OpenXML, LibreOffice and
Gotenberg paths are removed, so the host reads no `Documents` settings and the local stack runs no `gotenberg`
service. Two other runtime changes reach the pack:

- data sources refuse anonymous callers unless they set `allowUnauthorizedAccess`, behind
  `DataSources:EnforceAuthentication` (default `true`), which the local stack turns off;
- an external user of another application that shares the database gets `Authentication:DefaultRole` on first
  sign-in, when `AutoApprove` is `true`.

The `dgf` sample gains three document-demo entities, and the showcase gains five PdfViewer pages. 1.3.1 also
collated the `.next` fragments the 1.3.0 pack cited into `RELEASE-1.3.0.md`, so 11 cited fragments went missing
and were re-sourced there, word for word. Four knowledge files changed facts: `application-layout.md`,
`component-catalogue.md`, `data-model.md`, and the vendored schema set (descriptions only).
