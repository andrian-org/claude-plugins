- **`composition-specs.md`:** `custom.css` and the design tokens are served `no-cache`, and a replaced `index.html`
  must link the five token stylesheets.
- **`data-model.md`:** a textarea applies `pattern`, a tab can be hidden, and dynamic-SQL lookups now resolve.

  sample stack's demo accounts, and the five token links.

No machine-read table changed.

1.2.0, so it compared 1.2.0 with itself. Every agent read the changes with `git diff 8534230d4 1.2.0` instead. The tool
now starts from the tag the facts' own stamps name (`read_position`), with a regression test.
