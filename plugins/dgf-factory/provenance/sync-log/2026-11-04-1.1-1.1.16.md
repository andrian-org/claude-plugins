## Summary

DGF 1.1.16 adds two dispatchable components, AutoComplete and Chart (`RegisterComponentService` 34 → 36,
`ComponentType` 67 → 69 members). It regenerates every JSON schema with camelCase property names and camelCase string
enums, keeping the C# member names in `x-enumNames`. It adds a tenth XSD, `application-sitemap.xsd`, and lets
`process.xsd` read `OnInit`'s children in any order with `StoredProcedureActivity`. `profile.xsd` now compiles, and
`workflow.xsd` declares `StateProcess`. The MCP now indexes the six DataSource schemas by discriminator. Nine knowledge
files moved; `reference-graph.md` had no drifted source.
