## Summary

DGF 1.3.0 adds a role display name: an optional `AspNetRoles.RoleDisplayName`, read with raw SQL that falls back to
the role name. It also makes the sitemap's `roles` / `deny` lists trim each name and drop empty ones. Further
changes:

- translations are requested only when `localization.languages` is set;
- the role-switch check now uses `NormalizeKey`;
- Application Insights is removed and Redis moves to StackExchange.Redis 3;
- sidebar counts run in parallel under `DGF_ROUTER_COUNT_CONCURRENCY`;
- one more sample `String` field.

Four knowledge files moved. The trimming is the first behaviour that differs **between packs inside a validator**:
`roles.py` used to hard-code DGF ≤ 1.2's untrimmed split. The split rule now lives in each pack's `role-sources`
table (`Separator` `,` versus `, trimmed`), so one codebase reads every line correctly.
