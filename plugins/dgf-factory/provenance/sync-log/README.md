# Sync logs

One file per time `/dgf-sync` brought a knowledge pack to a DGF release tag. The file name is
`<YYYY-MM-DD>-<X.Y>-<X.Y.Z>.md`, and each holds the per-source triage behind the edit
(`.claude/skills/dgf-sync/references/SYNC-LOG-FORMAT.md`).

These are maintainer records, like the ledgers beside them: never shipped (ADR 0030), and not ledgers either.
`tools/check_knowledge_stamps.py` skips this folder.
