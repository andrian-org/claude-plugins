# Blast radius trusted the filesystem's case, and the model check read the loaders' happy path only

**Date:** 2026-09-27 10:33
**Files:** scripts/audit_root.py, scripts/lib/graph.py, scripts/lib/edges.py, scripts/lib/model.py, scripts/lib/workspace.py, scripts/lib/knowledge.py, scripts/validate_model.py, knowledge/reference-graph.md, knowledge/data-model.md, knowledge/README.md, provenance/knowledge/reference-graph.md, skills/dgf-component/SKILL.md, skills/dgf-process/SKILL.md, skills/dgf-model/SKILL.md, docs/adr/0023-dgf-specific-skills.md, docs/adr/0024-learning-loop-revised.md, docs/pipeline.md, docs/getting-started.md, docs/skill-authoring.md, .ai-factory/ARCHITECTURE.md, AGENTS.md, tests/test_audit_root.py, tests/test_graph.py, tests/test_model.py, tests/test_validate_model.py, tests/test_knowledge.py, tests/test_verify_gate.py
**Severity:** high

## Problem

`/aif-verify` on the DGF-specific-skills branch found that blast radius could answer "nothing
reaches this file" for a file 18 processes reach. Over DGF's samples,
`audit_root.py --reach webasm/FM/_WORKFLOW/ax.notify/_workflow.xml` exited `0` with `NONE` in both
applications on macOS. The file on disk is `AX.Notify`; on Linux the same command exits `3`.

The model check was also wrong in both directions on inputs no sample holds:

- It **passed** an `extract` with neither `table` nor `dialog`, and a `slavegrid` with no `table`.
  The runtime throws on both.
- It **passed**, with only a warning, a grid folder that exists without its `_grid.xml` when the table
  has a `default` grid. The runtime's copy throws there.
- It **blocked** hidden cells in a form with no `<tabs>`, which the runtime never binds.
- The graph also added a node for a dynamic edge's missing static target.

## Root Cause

- **The reach target was the one path lookup written by hand.** `reach_one` checked the target with
  `(root / rel).is_file()`, the pattern `RULES.md` rule 2 forbids. Every resolver used
  `workspace.exact_file`, but a user-typed CLI argument was not thought of as "a DGF file reference".
  The graph's nodes carry the case on disk, so a wrongly cased target matched no node and reach found
  none. The result was a false zero, the most dangerous answer a blast-radius report can give.
- **The loaders were read for "what happens when the target is missing", never for "what happens when
  the name is empty"** or for "what happens when the folder exists but the file does not".
  - One general rule, "an empty value is no reference", was written into `reference-graph.md` §1 and
    `edges._one`. It contradicted `data-model.md` §3.1–§3.2, which already said an empty table name
    throws. The resolvers' empty-name branches were therefore unreachable.
  - `When absent` was modelled per edge, but the copy-into-an-existing-folder throw depends on the
    workspace's state, not the edge.
  - The hidden-cell rule missed `if (Tabs == null) return;` one line above the `AddFields` call it cited.
- **A dynamic edge's status replaced its resolution.** `_edge` set `status = dynamic` before
  `build` tested `!= unresolved`, so an unresolved static target became a node.

## Solution

- **Reach checks its target exactly.** `reach_one` uses `workspace.exact_file`. A case-only match is
  `AUDIT_REACH_NOT_ARTIFACT` (exit `3`), and the message names the file as it is on disk.
- **A new `When empty` column in `reference-edges`**, read from the runtime:
  - `throws` for `extract-dialog`, `slavegrid-table` and `slavegrid-grid`;
  - `none` for `extract-table`, `extract-view` and `datasource-step`;
  - `unknown` elsewhere, which keeps today's behaviour;
  - `—` for `form-table`, which names no attribute.

  `edges._one` passes an empty value to the resolver only where the column is `throws`. So the rule
  is data, and no script names an edge kind.
- **The copy throw.**
  - `workspace.Unresolved` gains `throws`. `model.resolve_form` and `resolve_grid` set it when the
    folder exists exactly and the table's `default` file exists (`FormManager.Copy`,
    `EditableGridManager.Copy`).
  - `validate_model.py` blocks on it.
  - `graph.py` reports that edge's `When absent` as `throws`, and carries the reason, so the audit
    reports a `template` edge that throws here.
- **`model.cells()`** binds nothing in a form with no `tabs` element.
- **`build()`** adds a node only for a static target that resolved.
- **Smaller fixes:**
  - A blank grid name is `default` (`IsNullOrWhiteSpace`).
  - `unreached()` lost its ignored `kind` parameter.
  - `validate_model.py` messages no longer read "names ``" or "— it a name…".
  - `_resolve` traces carry `owner`, `scope` and `app`.
- **Docs and ADRs:**
  - ADR 0023 gets a dated erratum (grids clean their table name), and ADR 0024 gets one (its Context
    count).
  - `knowledge/README.md` §7 and `ARCHITECTURE.md` state the `Checked by` exception.
  - `/dgf-component`, `/dgf-process` and `/dgf-model` gain the missing exit tables.
- **Tests:** 15 regression tests failed before the fix and pass after it. More were added: coverage
  of the six untested edge kinds, a rebuild that must see a changed file, and the missing
  `APP_DEPENDENT` negative case. Three new known-bad cases cover the three new blocking paths:
  `model-extract-neither-table-nor-dialog`, `model-slavegrid-no-table` and
  `model-grid-folder-without-file`. DGF's samples are unchanged: known-good is still CLEAN with the same
  counts.

## Prevention

- **Every path the plugin checks goes through `workspace.exact_file` or `exact_child`**, including a
  CLI argument, a `--changed` path and a template path. Grep new code for `.exists(`, `.is_file(` and
  `.is_dir(` on anything not already matched exactly.
- **Read each loader for four inputs, not one:** the target present, missing, named by an empty
  value, and its folder present without its file. Also read the lines above the call you cite: an
  early `return` changes what is bound.
- **A general rule in a knowledge file ("an empty value is no reference") must hold for every row.**
  If one row differs, the difference belongs in a column. Check it against every sibling knowledge
  file before stating it.
- **A result that carries two facts keeps both.** Here that was "dynamic" and "unresolved". Test that
  a dynamic edge to a missing file adds no node.
- **Test a blast-radius tool for a false zero.** A reach that finds nothing must be tested on a path
  that exists in another case.
